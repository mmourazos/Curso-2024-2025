# Conexiones cifradas MySQL

## Pasos a seguir en el vídeo

1. Crear una máquina virtual con Ubuntu Server 24.04 LTS.
2. Configurar el servidor para que acepte conexiones remotas.
3. Crear un usuario que pueda conectarse desde cualquier IP.
4. Comprobar que la conexión funciona correctamente.
5. Modificar el usuario para que requiera SSL para conectarse.
6. Comprobar que no es posible realizar la conexión sin SSL.
7. Cambiar la configuración del servidor para que acepte conexiones SSL.
8. Generar los certificados necesarios para la conexión SSL.
9. Realizar la conexión de nuevo y comprobar que funciona correctamente.
